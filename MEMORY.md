## Key decisions (why)
- **D1 — Exact esim70 clone, not Kinetic Horizon.** User requirement: the storefront must look/behave like esim70.com. The mockup-derived "Kinetic Horizon" design (Hanken/Inter, blue+yellow, `/destinations/[country]`, hand-rolled components) was wrong. Corrected across all docs.
- **D2 — shadcn/ui.** esim70 is built on shadcn (Radix + CVA). Prior build hand-rolled primitives — the #1 correction. Compose from shadcn; add only components used.
- **D3 — Oswald + Poppins.** esim70's exact fonts (Oswald uppercase display, Poppins body). Replaces Hanken/Inter.
- **D4 — Tokens:** shadcn set `--primary #615de5` + accents electric-blue `#3535ff` (CTA/active), lime `#c6f135` (one hero word), red `#e40014` (ticker/mobile Sign-in), radius `.625rem`, cards 22px, pill buttons. Replaces Kinetic tokens.
- **D5 — Routing `/esim/[slug]`** for country **and** region (unified); 308-redirect legacy `/destinations/[country]`. Matches esim70.
- **D6 — Per-day pricing** is the headline unit: `perDay = retail_price_usd / validity_days`; country "from" = min per-day. Matches esim70's "from $X/day". USD canonical; local display-only.
- **D7 — JSON-driven content.** All marketing copy in `content/*.json` (was hardcoded in page files). Per-country editorial in `content/countries/{slug}.json` (drives index gate).
- **D8 — Motion:** framer-motion (scroll-reveal) + embla (carousels) + CSS marquee (ticker); all reduced-motion gated.
- **D9 — Homepage section set (12):** hero → red ticker → what-is-eSIM → where-travelers-go (tabs) → quiz → how-it-works → why-pick(5) → reviews carousel → CTA band → stats band → FAQ(7) → app CTA → footer. Prior build had ~4.
- **D10 — Simplicity mandate.** Least code that works; no over-engineering; **no code comments/docstrings** in source (user directive). Docs carry the explanation.
